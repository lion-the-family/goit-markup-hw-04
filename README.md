## Web Studio

**Web Studio** is a responsive HTML/CSS template designed for digital marketing or business services. It includes a modern layout with a clean header, main promotional section, and footer with social media links. The project uses:

* **modern-normalize** for consistent default styles
* **Google Fonts** (Raleway & Roboto) for typography
* Organized structure with reusable CSS in `/css/styles.css`


### 🧩 General Styles

* `Roboto` and `Raleway` fonts via Google Fonts.
* Global reset for margin/padding and box-sizing.
* Responsive `.container` with max width of `1158px`.
* Smooth transition effects on `hover`/`focus`.

### 🧭 Header

* Flex layout for navigation and contact info.
* Styled logo, nav menu with active link underline effect.
* Contact links with hover color change.

### 🖼️ Hero Section (1st Section)

* Full-width section with background image and dark overlay.
* Centered heading and CTA button.

### ✨ Features Section (2nd Section)

* List of feature items with icons.
* Text with modern spacing and readability.

### 👥 Team Section (3rd Section)

* Profile cards with names, roles, and social media buttons.
* Hover effect on social icons.

### 🎨 Portfolio Section (4th Section)

* Responsive project cards.
* Overlay animation on hover revealing project info.

### 🔻 Footer

* Logo and description block.
* Social links with hover transitions.
* Dark background and contrasting text for clarity.

---


### How to Use

1. Clone or download the project.
2. Open `index.html` in your browser.
3. Customize the content and styles as needed.
